# WikiGen
A wiki website generator for [tModLoader](https://github.com/tmodloader/tModLoader) mods.

# Usage
Install and build the WikiGen mod via ModSources. Set the "Target Mod Name" to your desired mod's internal name on the WikiGen config. (by default ExampleMod)

Every time your game reloads, the wiki will be regenerated. You can open the wiki folder via the button located on the WikiGen config.

# Dependencies
- [ImageSharp](https://github.com/SixLabors/ImageSharp)
